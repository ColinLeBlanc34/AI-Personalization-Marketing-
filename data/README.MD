# Data Directory Documentation

## Dataset 1: Internet Users (% of population)

**Source:** World Bank – World Development Indicators (WDI)  
**Indicator Code:** IT.NET.USER.ZS  
**Date Accessed:** Tues/Feb24/2026
**URL:** https://data.worldbank.org  

**Description:**  
This dataset measures the percentage of individuals using the internet within a country each year.

**Relevance to Project:**  
Internet usage is used as a proxy for digital market penetration. Rising internet adoption increases digital marketing exposure and competitive pressure, contributing to the reinforcing loop that drives firms toward AI-driven personalization strategies.

## Dataset 2: Secure Internet Servers (per 1 million people)

**Source:** World Bank – World Development Indicators (WDI)  
**Indicator Code:** IT.NET.SECR.P6  
**Date Accessed:** Tues/Feb24/2026
**URL:** https://data.worldbank.org  

**Description:**  
This dataset reports the number of secure internet servers per one million people, serving as a proxy for digital commerce infrastructure.

**Relevance to Project:**  
Secure server growth indicates rising e-commerce activity and greater transactional data generation, increasing the economic incentive to deploy AI-based personalization.

## Dataset 5: Regulatory Quality Index

**Source:** World Bank – Worldwide Governance Indicators (WGI)  
**Indicator Code:** GE.REG.QA.EST  
**Date Accessed:** Tues/Feb24/2026
**URL:** https://data.worldbank.org  

**Description:**  
This dataset measures perceptions of regulatory quality and governance effectiveness.

**Relevance to Project:**  
Regulatory strength acts as a system constraint, influencing the balancing loop that limits aggressive AI personalization due to compliance and trust considerations.
